# bthsoftware.com

Marketing site for BTH Software Solutions.

Static HTML, CSS and JS. No build step.

## Run locally

```
npx serve .
```

or open `index.html` in a browser.

## Deploy

GitHub Pages from `main`, root folder. `CNAME` points the site at bthsoftware.com.

## Structure

- `index.html` - the page
- `assets/css/site.css` - styles and brand tokens
- `assets/js/site.js` - nav, scroll reveal, small demo animation
- `assets/img/` - logo mark (from the BTH logo kit) and social image
